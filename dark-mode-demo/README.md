# Plan & Record · A 轻柔冷灰蓝本地 Demo

启动：在项目根目录执行 `npm --prefix dark-mode-demo run dev -- --port 5190 --strictPort`。
打开 http://127.0.0.1:5190/ 。第一次打开默认深色，右上角可切换明暗模式；目录可进入全部六个页面。

## 范围与数据

独立复制现有本地 Demo 的页面和交互。已与当前正式源码核对：主要差异为近期云端存储适配；本预览保留本地存储适配，使长期计划、每日计划、旅行和心情日记可操作。原有布局、模块颜色、纸张形状和首页文件夹动画保留。

没有复制任何 .env、凭据或 Vercel 配置。`src/lib/supabase.ts` 强制返回 null，不读取环境配置、不创建客户端。登录/注册仅供视觉查看；账户名称、任务、旅行、日记和长期计划使用本浏览器示例数据。头像预览使用临时本地 URL。天气和目的地图片仍使用原项目公开外部资源。

正式目录 `src/`、`public/` 未修改；没有提交、推送、部署、执行 SQL 或迁移。

## 统一配色入口

**仅维护 `public/dark-mode.css` 一份主题文件。** React 入口通过 Vite 导入，文件夹 iframe 引用同一文件并观察父页面的主题变化。所有新深色样式均由 `html.dark` 限定，浅色视觉保持原样。

顶部 `--dm-*` 变量包含画布、玻璃面板、弹层、输入框、文本、边框、Hover、Selected、Focus、危险动作、模块色、文件夹和图表颜色。背景图遮罩由 `--dm-bg-top` / `--dm-bg-bottom` 控制。

后续是现有 Tailwind 工具类映射及长期计划、手记纸张、文件夹的专用主题规则。无需逐页重新修改颜色。
