# Deployment

This project is deployed on Vercel.

Production URL:

https://plan-record-x5d8.vercel.app

## Vercel Settings

Use the following settings for this Vite project:

```text
Framework Preset: Vite
Install Command: npm install
Build Command: npm run build
Output Directory: dist
```

The app stores task data in the browser through LocalStorage. The deployed website is shared online, but task records are still local to each browser and device.
